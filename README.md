A tiny Node 22 program for the make.fun bounty
[Make the AI Judge Laugh: the Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232).

`main.ts` writes one office joke to `/output/entry.txt`: a calendar blocks
an hour for focus time, then the manager books that very hour to ask why
there is never any focus time. The protection itself is the thing that gets
eaten — a specific calendar detail with a circular turn that lands in the
last few words. No network, no randomness, no input — the same line on every
run.

## Run it

```sh
node main.ts
```
